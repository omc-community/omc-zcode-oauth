# Source note

The ZCode prompt compatibility data in `go/assets/prompt.json` is extracted from
the official ZCode repository at tag `v3.14.3` using
`scripts/extract-vendor-prompt.mjs`.

Source: https://github.com/zai-org/ZCode/tree/v3.14.3

The plugin's Go implementation is independent.

Z.AI and BigModel.cn names and logos belong to their respective owners.

`assets/logo.png` is this plugin's own face in a store: the ZCode mark drawn on the
OMC sticker the ecosystem's plugins share. It identifies the plugin rather than the
service, and no sign-in card uses it.
